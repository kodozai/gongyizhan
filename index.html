常见问题

公益站是什么意思

公益站是由个人自费搭建、免费开放给社区使用的 AI API 中转站，多数用 New API / One API 搭建，靠签到、注册赠送等方式发放免费额度；它不是官方服务，可能随时限流或停止，本站每日探测其存活状态。 查看健康度说明

公益API不用登录

本站收录的公益站中，已知登录方式的 34 家都需要注册或第三方登录（GitHub / LinuxDo / 邮箱），这是站方防止滥用的做法；本站不收录、也不提供免登录的共享 Key。

公益API常用接口有哪些

多数公益站基于 New API / One API 搭建，提供 OpenAI 兼容的 /v1/chat/completions 与 Anthropic 兼容的 /v1/messages 接口，具体可用模型和端点以各站文档为准。

站长自费分享额度帮助社区体验和开发，通常要求珍惜使用（勿压测、勿囤号、勿外传大群）；具体以各站公告为准。
